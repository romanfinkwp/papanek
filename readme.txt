== Description ==

Papanek is a minimalistic block theme with Full Site Editing features, developed for agencies and freelancers to quickly launch a simple and clear website. Create effortless, simple, and clear landing pages with 54 ready-to-use patterns. Inspired by Victor Papanek.

== Installation ==

1. Check you version of WordPress, it should be 6.2 or later.
2. Upload the theme.
3. Activate the theme.
