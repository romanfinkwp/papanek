# Papanek

[![WordPress.org version](https://img.shields.io/wordpress/theme/v/papanek)](https://wordpress.org/themes/papanek/) [![Active installs](https://img.shields.io/wordpress/theme/installs/papanek)](https://wordpress.org/themes/papanek/) [![License: GPL v2 or later](https://img.shields.io/badge/license-GPLv2%2B-blue)](https://www.gnu.org/licenses/gpl-2.0.html)

Papanek is a minimalistic block theme with Full Site Editing features, developed for agencies and freelancers to quickly launch a simple and clear website. Create effortless, simple, and clear landing pages with 54 ready-to-use patterns. Inspired by Victor Papanek.

![Screenshot](screenshot.png)

- **WordPress.org:** https://wordpress.org/themes/papanek/
- **Live preview:** https://wp-themes.com/papanek/

## Installation

1. Check you version of WordPress, it should be 6.2 or later.
2. Upload the theme.
3. Activate the theme.

To install the development version from this repository, download it as a ZIP (Code > Download ZIP), rename the folder inside to `papanek` and upload it in Appearance > Themes > Add New Theme > Upload Theme.

## Requirements

- WordPress 6.2 or later
- Tested up to WordPress 7.1
- PHP 7.4 or later
